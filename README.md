# 🏠 Real Estate AI – Price Prediction System

An AI-powered web application that predicts residential property prices using Machine Learning. Users can estimate house prices based on location, area, BHK, and bathrooms, or upload their own dataset to train a custom prediction model.

## 🌐 Live Demo

🚀 **Deployed App:**
https://real-estate-price-prediction-ai.streamlit.app/

## ✨ Features

* 🏡 House price prediction using AI
* 📍 Location-based valuation
* 📏 Area, BHK, and bathroom-based predictions
* 📂 Upload your own CSV dataset for custom model training
* 🧹 Automated data cleaning and preprocessing
* 🤖 Linear Regression-based prediction model
* 📊 Interactive Streamlit dashboard
* 📈 Visual insights and model evaluation metrics

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Seaborn
* Streamlit

## 🚀 How It Works

1. Enter property details (Location, Area, BHK, Bathrooms)
2. The system preprocesses the input
3. The trained ML model predicts the property price
4. Users can optionally upload their own dataset for personalized model training
